Khushi Online Centre - images checklist

  1. Neeche ki table mein "Google Images me dekhein" par click karein.
  2. Achhi, saaf (high quality) image par right-click karke Save image as... karein. Sarkari logo ho to us yojana ki official website se lena behtar hai.
  3. File ko bilkul table wale naam aur folder mein rakh dein (png / jpg / webp chalega).
  4. Site refresh karein - image apne aap dikhne lagegi. Code badalne ki zaroorat nahi.

Dhyan: web ki har image par kisi ka copyright hota hai. Sarkari logo sirf pehchaan ke liye aur unke niyam ke hisaab se use karein. Hero/shop ki photo aapki apni dukaan ki ho to sabse achhi rahegi.
